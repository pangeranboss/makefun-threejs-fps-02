**FOUNDRY LINE** — a round-based tactical FPS in the browser, built on three.js 0.187.0. Five-versus-five rounds on an original industrial foundry map: plant or defuse the charge, out-shoot the other squad, and spend your round earnings in the buy menu. Bots run routes, hold angles, rotate on the plant and defuse; gunplay has recoil, spread, headshots and movement penalties, and the simulation runs on a fixed 60 Hz step apart from rendering.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Click to lock the mouse, WASD to move, mouse to aim, click to fire, R to reload, B for the buy menu, E to plant/defuse, G for grenades, Ctrl to crouch, Shift to walk, Esc to pause.
